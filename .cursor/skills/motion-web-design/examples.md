# 案例

## 直接套

**用户**：套 dreamcore-landing

**Agent**：读 `prompts/dreamcore-landing.md` → 输出完整 Prompt 或开始写代码。

## 微调品牌

**用户**：用 interactive-discovery，品牌改成「小氵AI」

**Agent**：读模板 → 只替换 Lithos / 文案 / CTA → 输出完整 Prompt。

## 换平台类型

**用户**：找一个 WEB 的 Portfolio 模板

**Agent**：筛 `catalog.json` 中 `platform: "website"` + category 含 Portfolio → 推荐 3 条。

## 混搭

**用户**：Electric 的 neon 背景 + Forma 的 bento Features

**Agent**：以 electric 为骨架，只替换 Features 章节描述为 bento 规格，检查 dark 配色一致。
